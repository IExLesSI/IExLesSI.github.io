Privacy Policy – Exless Upload

Last updated: 27 November 2026

Who we are

Exless Upload is a private tool operated by Exless Studio (contact: exless.media@gmail.com). It is used only by Exless Studio to manage its own YouTube channel.

What data the tool accesses

When the studio owner signs in with Google, Exless Upload receives access to the studio's own YouTube channel through the YouTube Data API (scope youtube.force-ssl). It uses this access only to:

  • upload the studio's own videos and set their title, description, privacy status and AI-content disclosure,
  • read comments on the studio's own videos and post replies approved by the studio owner.

The tool does not access any other user's Google or YouTube account.

How data is stored

The access token is stored only on the studio's own computer, encrypted in the operating system's keyring. Comment text that the tool reads is used only to draft replies and is not sold, shared or transferred to third parties.

Google API Services

Exless Upload's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using YouTube API Services, the tool is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. After revocation, the locally stored token is deleted.

Contact

Questions about this policy: exless.media@gmail.com
