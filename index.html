Exless Studio

Exless Studio is a small independent studio producing short animated stories, including the horror channel Dimlit Tales on YouTube.

Exless Upload

Exless Upload is a private tool used only by Exless Studio. It uses the YouTube Data API to upload the studio's own videos to its own YouTube channel, set titles, descriptions and AI-content disclosures, and read and reply to comments on that channel.

The tool is not offered to other users. It does not access any other person's YouTube or Google account.
